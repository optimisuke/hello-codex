# Hello Codex: Python Generator Examples

シンプルなPythonのジェネレーターの書き方と使い方をまとめた小さなスクリプトです。
`generator_example.py`を実行すると、以下の例を確認できます。

- 1から任意の上限まで数える基本的なジェネレーター関数
- 別のジェネレーターを受け取り、その値を平方にするチェーン例
- 無限に偶数を返すジェネレーターを `next` で途中で止める例
- 内包表記で書いたジェネレーター式による3乗の計算

## 使い方

```bash
python generator_example.py
```

出力にはジェネレーターの反復処理と途中停止の様子が表示されます。
